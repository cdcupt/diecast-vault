# Diecast Vault (working title)

iOS app to digitize a physical diecast car collection (focus: Mini GT 1:64).
Scan a real car with your iPhone → on-device 3D model → bonded to its Mini GT
catalog number → view/rotate in 3D/AR → store locally (optional iCloud) →
optionally share to a community library so others can reuse the same scan.

Built with the SDD pipeline. Artifacts live in `docs/pipeline/`.

Status: PRD / kickoff in progress.
